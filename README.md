# PlanDay

Консольна java-програма для планування розкладу. Дані зберігаються в бд PostgreSQL. Проєкт використовує java 21, maven і JDBC.

## Документація

- [SDD](SDD.md) - опис архітектури, вимог і моделі даних.
- [SDLC](SDLC.md) - етапи розробки та план роботи.

## Технології

- Java 21
- Maven
- PostgreSQL
- JDBC
