# PlanDay

PlanDay - консольна програма на Java для планування розкладу. Користувач може додавати справи, переглядати розклад, змінювати та видаляти записи. Дані зберігаються у Postgresql.

## Можливості:

- додати запис з назвою, датою, часом, тривалістю, категорією та приміткою;
- показати розклад на обраний день;
- показати розклад на тиждень;
- змінити або видалити запис за його айді;
- перевірити, щоб два записи не перетиналися за часом;
- зберегти записи у базі даних postgresql.

## Технології

- Java 21
- Maven
- PostgreSQL
- JDBC

## Підготовка бази даних

1. Встановити та запустити Postgresql.
2. Створити базу даних з назвою `plan_day`.
3. Виконати sql зі файлу `src/main/resources/db/schema.sql` у створеній базі.

## Налаштування підключення

За замовчуванням програма підключається до бази за адресою `jdbc:postgresql://localhost:5432/plan_day` під користувачем `postgres`.

Перед запуском потрібно вказати пароль PostgreSQL у змінній середовища. Для `cmd`:

```cmd
set PLANDAY_DB_PASSWORD=ваш_пароль
```

За потреби можна також змінити адресу бази та користувача:

```cmd
set PLANDAY_DB_URL=jdbc:postgresql://localhost:5432/plan_day
set PLANDAY_DB_USER=postgres
```

## Запуск

У папці проєкту виконати:

```cmd
mvn clean package
mvn exec:java
```

Після запуску з'явиться меню. Оберіть пункт від `0` до `5`.
